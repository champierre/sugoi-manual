# シェイプを整列させる

キートップの真ん中にシェイプをそろえるやり方です。

並べたいシェイプを同時に選んで「整列」を押すと、整列ボタンが出てきます。整列させたい位置の ● ボタンを押すと、選択されたシェイプがその位置に並びます。
