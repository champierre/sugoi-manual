# キークリッカーとは

キーボードのスイッチに自作のキートップをつけて、カチカチとなるおもちゃを作ります。

<figure><img src="/images/slide02-2.jpg" alt="キースイッチ、キーボックス、キートップ"><figcaption>上: キースイッチ(青)とキーボックス、下: キートップ</figcaption></figure>
</div>

キークリッカーは、次の 3 つの部品でできています。

- **キースイッチ** … キーボードに使われているスイッチ。押すとカチカチ鳴ります。
- **キーボックス** … キースイッチをはめこむ箱。3D プリントします。
- **キートップ** … いちばん上にかぶせる部品。**これをデザインします。** 3D プリントします。
