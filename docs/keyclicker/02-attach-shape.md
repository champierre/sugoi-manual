# シェイプをはりつける

キートップの上の面に、好きなシェイプをぴったりとはりつけます。

<div class="steps">
<figure><img src="/images/slide04-1.jpg" alt="クルーズ(じしゃくアイコン)"><figcaption>クルーズ(じしゃくアイコン)を押してからドラッグすると、いろんな面にくっつけられる</figcaption></figure>
<figure><img src="/images/slide04-2.jpg" alt="キートップにシェイプをはりつけたところ"><figcaption>キートップの上の面にシェイプをはりつける</figcaption></figure>
<figure><img src="/images/slide04-3.jpg" alt="フラットビューで横から見たところ"><figcaption>「右」をクリックして横から見る。フラットビューにすると、くっついているかどうかわかる</figcaption></figure>
</div>

::: tip くっついているか確かめる
フラットビューにして横から見ると、シェイプがキートップから浮いていないか確認できます。
:::
