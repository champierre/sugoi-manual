# ひな型をコピーする

TinkerCAD(ティンカーキャド)で、キークリッカーの 3D モデルのひな型をコピーして編集します。

TinkerCAD にログインすると、ひな型を「コピーして編集」できるようになります。

## 光るキークリッカーのひな型

LED を入れて光らせるタイプのひな型です。

![光るキークリッカーのひな型](/images/slide03-2.jpg)

- 赤い方が **キートップ**(ここになにかつける)
- 緑の方が **キーボックス**(形を変えない)

👉 [https://www.tinkercad.com/things/kg0e1ci1WRW-keyclicker-flash](https://www.tinkercad.com/things/kg0e1ci1WRW-keyclicker-flash)

## 光らないキークリッカーのひな型

LED を使わない、シンプルなタイプのひな型です。

![キークリッカーのひな型](/images/slide13-2.jpg)

- 赤い方が **キートップ**(ここになにかつける)
- 水色の方が **キーボックス**(形を変えない)

👉 [https://www.tinkercad.com/things/jFw1sMmRYSp-keycliker-plain](https://www.tinkercad.com/things/jFw1sMmRYSp-keycliker-plain)
